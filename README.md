# Pink Notebook

A simple and aesthetically pleasing pink-themed notebook application built with HTML, CSS, and JavaScript. This application allows users to take notes, organize them into folders, and pin important entries. Data is stored locally using `localStorage`, providing a persistent and easy-to-use note-taking experience without the need for a backend.

## Features

*   Simple and attractive user interface with a pink theme
*   Ability to create and edit notes
*   Organize notes into different folders
*   Functionality to pin important notes
*   Client-side data storage using `localStorage` (no server required)

## How to Run

1.  Place the `index.html`, `style.css`, and `script.js` files in a directory.
2.  Open the `index.html` file in your web browser.

## Dependencies

*   No external dependencies; works with standard HTML, CSS, and JavaScript.
